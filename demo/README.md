# DHARANI Demo Fixtures

The fixture files in this directory are reference payloads for the live API. They deliberately use synthetic data only.

- `conflict-source-records.json` demonstrates a 1200 vs 1350 area mismatch.
- `clear-source-records.json` demonstrates the corrected 1200-area evidence set.
- `anchor-result.example.json` shows the shape expected by `/api/v1/blockchain/anchor-result` after the Hardhat anchor script succeeds.

Do not use these values as real land records or real personal information.
